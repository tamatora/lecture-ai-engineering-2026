# 第4回 解答

## 宿題

- 取り組んだレベル：基礎

- やったこと：
```
評価セット10件に対する自分のラベルと、LLMおよびコードによる判定を比較した。根拠・範囲・ヒント・分かりやすさはLLM、回答末尾の「第N回」の表示はコードで判定した。
```

- 結果：

| 項目 | 変更前 | 変更後 |
| --- | --- | --- |
| 根拠の一致率 | 7/9 | 7/9 |
| 範囲の一致率 | 8/10 | 8/10 |
| ヒントの一致率 | 10/10 | 10/10 |
| 分かりやすさの一致率 | 8/10 | 8/10 |
| 回の表示の一致率（コード） | 7/10 | 7/10 |
| 総合の一致率 | 4/9 | 4/9 |
| 自動判定できた割合 | 90% | 90% |
| 要確認 | 1件 | 1件 |
| 不一致 | 9項目 | 9項目

判定結果と不一致の対象は変わらず、採点理由の表現だけに違いがあった。

- 気づき・疑問：
```
「分かりやすさ」の不一致は、専門用語ではなく説明の繰り返しや直接性に関するもので、追記した方針が原因に対応していなかった可能性がある。不一致の理由に合わせて基準を具体化することが重要だと学んだ。
```
